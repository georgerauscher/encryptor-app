# Contributing to encryptor.app

Thank you for your interest in encryptor.app!

This project is maintained by **[George A. Rauscher](https://rauscher.xyz)** (intelligent piXel GmbH).

## Reporting Bugs

If you encounter a bug or technical issue, we appreciate your report.

**Please follow these steps:**
1. **Search existing issues** to avoid duplicates.
2. **Open a new Issue** on GitHub.
3. **Include details:** Browser, OS, steps to reproduce, and what happened.

**Link:** [Open an Issue](https://github.com/georgerauscher/encryptor-app/issues)

## Security Vulnerabilities

**DO NOT report security vulnerabilities publicly.**

Please report them privately to: **george@rauscher.xyz**

We will investigate and address security issues as a priority.

## Pull Requests & Contributions

Currently, we are **NOT accepting Pull Requests** or code contributions.

To ensure the security, integrity, and maintainability of this zero-knowledge encryption tool, development is handled internally. Please do not submit PRs as they will likely be closed without review.

Thank you for using encryptor.app and respecting our development process.
